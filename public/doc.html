LIMN CORE

Professional Dynamic Realtime Database Engine

Overview

LIMN CORE is a professional backend engine built using Express.js, MariaDB, Socket.io, JWT Authentication and Dynamic CRUD APIs.


Express.js MariaDB Socket.io JWT Realtime

Installation

Clone Repository


git clone https://github.com/saikat19941/limn-core.git

Install Packages


npm install

Start Server


npm start

Authentication

JWT Login


POST /api/auth/login


{
  "email": "admin@limn.com",
  "password": "password"
}

JWT Header


Authorization: Bearer YOUR_TOKEN

API KEY Header


x-api-key: limn_sk_default_admin_key

CRUD API Examples

Fetch Databases


GET /api/databases

Fetch Tables


GET /api/databases/classicmodels/tables

Fetch Rows


GET /api/databases/classicmodels/customers

Insert Row


POST /api/databases/classicmodels/test


{
  "name": "Saikat"
}

Update Row


PUT /api/databases/classicmodels/test/1


{
  "name": "Updated"
}

Delete Row


DELETE /api/databases/classicmodels/test/1

Filtering & Pagination

Advanced Filtering


GET /api/databases/classicmodels/customers?creditLimit_gt=50000

LIKE Search


GET /api/databases/classicmodels/customers?customerName_like=Mini

Pagination


GET /api/databases/classicmodels/customers?page=1&limit=10

Sorting


GET /api/databases/classicmodels/customers?sortBy=customerName&order=ASC

Realtime Socket System

Join Table Room


socket.emit(
  "join_table",
  "classicmodels.test"
);

Listen Insert Event


socket.on("row_inserted", (data) => {
  console.log(data);
});

Listen Update Event


socket.on("row_updated", (data) => {
  console.log(data);
});

Listen Delete Event


socket.on("row_deleted", (data) => {
  console.log(data);
});
