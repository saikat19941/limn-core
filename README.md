# LIMN CORE

Dynamic Realtime Database API Engine using:

- Express.js
- MariaDB
- Socket.io
- JWT
- Dynamic CRUD API
- Filtering
- Pagination
- Sorting

## Features

- Dynamic Database Access
- Dynamic Table Access
- Dynamic CRUD Operations
- Advanced Filtering
- Pagination
- Sorting
- Secure Query Validation
- Connection Pooling
- Realtime Ready

## Tech Stack

- Node.js
- Express.js
- MariaDB
- Socket.io
- JWT
- Helmet
- Rate Limit

## Installation

```bash
npm install
```

## Run

```bash
npm start
```
